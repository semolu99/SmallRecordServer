# 인터넷 보안 프로젝트
***
## small Record Server
* 프로젝트 기간 : 2023.08.18 - 2023.11.28 ( 3 개월)
* 실제 개발 기간 : 2023.11.04 - 2023.11.24
* 사용한 기술 : Kotlin, Spring boot, MySQL
* 기여도 : 90 %
* 참여 인원 : 프론트 3인 백엔드 1인
* 프로젝트 설명
  * 개발 목적 
    * 육아에 미숙한 초보 부모들을 위하여 가이드라인을 제공해주며 아이들의 상태를 기록하고, 성장을 보다 쉽게 관찰 할 수 있도록 보조하는 어플
  * [시연 영상](https://youtu.be/B_BQ_26pDxg?si=pDNzcCoH6YYkD6_X&t=454, "유튜브 링크")
***
* 구현 기능
  * 회원가입, 로그인, 내 정보 조회, 내 정보 수정 등 기능을 구현했습니다.
  * 게시물 작성, 조회, 다이어리 작성, 조회의 기능을 구현했습니다.
  * 바코드 기능 식품 정보가 담긴 CSV를 MySQL에 주입하여 구현하였습니다.
  * GitHub을 통해 버전관리를 했습니다.
  * Postman을 이용해서 API를 직접 테스트하여, 빠르게 오류를 식별하고 수정했습니다.
  * JWT와 Spring Security를 활용하여 서버의 비인가 접근을 막는 방법을 적용했습니다.

* 협업 방식
  * 주 1회 대면 회의 및 개발
